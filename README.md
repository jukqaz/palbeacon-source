# PalBeacon — 공개 소스 스냅샷

팰비콘의 SvelteKit 웹/PWA, Tauri Windows 앱, Rust Core/Overlay와 데이터 추출 도구 소스입니다.
Pocketpair의 승인·후원·제휴를 받지 않은 비공식·비상업 팬 프로젝트입니다.

- 서비스: https://palbeacon.jukqaz.xyz/
- 이 저장소는 코드 참고용 공개 스냅샷입니다. 완성된 실행 패키지가 아닙니다.
- 게임 이미지·지도 타일·추출 데이터, 개인 세이브, 운영 설정, 과거 Git 이력과 작업 로그는 포함하지 않습니다.
- 원본 비공개 저장소는 삭제하거나 이력을 재작성하지 않았습니다.

## 빌드 경계

런타임 버전은 mise.toml, rust-toolchain.toml, global.json에 고정돼 있습니다.
pnpm install --frozen-lockfile 및 pnpm quality:security로 의존성을 확인할 수 있습니다.
실제 UI 빌드·게임 기반 테스트·Windows 번들은 별도로 적법하게 확보한 게임 데이터,
지도 리소스, 앱 아이콘과 테스트 자료가 필요합니다. 누락 데이터를 가짜 값이나 네트워크
자동 다운로드로 대체하지 않습니다. 원본 배포용 CI는 이 소스 스냅샷에 복제하지 않습니다.
공개 CI는 스냅샷 무결성과 의존성 보안을 검사하며 제품 전체 테스트 통과를 뜻하지 않습니다.
이 고정 스냅샷에는 일반 버전 업데이트 PR을 생성하지 않습니다. 보안 알림과
보안 업데이트는 유지하며, 보안 수정 시에는 검토 후 무결성 목록도 함께 갱신해야 합니다.

## 권리

공개 열람과 오픈소스 라이선스 부여는 다릅니다. 새 저장소 전체 라이선스를 임의로
추가하지 않았습니다. 기존 파일·패키지의 라이선스 및 third_party 고지를 따르세요.
Palworld 명칭, 게임 콘텐츠와 이미지의 권리는 Pocketpair 및 각 권리자에게 있습니다.
이 저장소는 해당 게임 리소스의 재배포 권한을 부여하지 않습니다.

## 상태

의존성 보안 수정이 포함된 코드 스냅샷입니다. 원본 PR의 원격 CI 및 최신 배포가
완료됐다는 의미는 아닙니다. Linux Tauri는 지원 대상이 아니며 해당 GTK/glib
잠금파일 경고는 해결됐다고 주장하지 않습니다.
Rustls는 TLS 보안 수정 버전 0.23.45이며 공개 CI에서 JavaScript 의존성과
공용 Rust 잠금파일을 검사합니다. Tauri의 플랫폼별 경고를 모두 해결했다는 뜻은 아닙니다.
